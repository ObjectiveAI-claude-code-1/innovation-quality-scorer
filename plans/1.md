# Implementation Plan: Innovation Quality Scorer

## Overview

This plan describes the implementation of the `innovation-quality-scorer` function, a scalar function that evaluates startup ideas for innovative merit across five dimensions: Conceptual Novelty, Technical/Business Model Innovation, Insight Depth, Cliché Avoidance, and First-Principles Thinking.

---

## 1. Input Schema Structure

### Schema Definition

```json
{
  "type": "object",
  "description": "Input for the innovation quality scorer",
  "properties": {
    "idea": {
      "anyOf": [
        {
          "type": "string",
          "description": "A text-based startup idea pitch or description"
        },
        {
          "type": "image",
          "description": "An image-based pitch (pitch deck slide, mockup, diagram)"
        },
        {
          "type": "audio",
          "description": "An audio pitch (verbal pitch, podcast clip)"
        },
        {
          "type": "video",
          "description": "A video pitch (demo video, pitch recording)"
        },
        {
          "type": "array",
          "description": "A composite pitch with multiple parts (e.g., slides + narration)",
          "items": {
            "anyOf": [
              { "type": "string" },
              { "type": "image" },
              { "type": "audio" },
              { "type": "video" }
            ]
          }
        }
      ]
    }
  },
  "required": ["idea"]
}
```

### Field Descriptions

- **idea**: The startup idea to evaluate. Supports multiple modalities:
  - `string`: Text description, one-liner, or detailed pitch
  - `image`: Visual pitch deck slide, product mockup, or diagram
  - `audio`: Verbal pitch or audio explanation
  - `video`: Demo video, pitch recording, or video explanation
  - `array`: Composite input combining multiple formats (e.g., slides with audio narration)

### Input Maps

**No input maps are needed.** Each task evaluates the same `idea` input directly. The input is not a collection requiring mapped execution—it's a single startup idea (potentially multi-modal) evaluated holistically.

## 2. Function Definition Structure

### Type and Description

```json
{
  "type": "scalar.function",
  "description": "Evaluates the innovative merit of a startup idea. Returns a score from 0 (purely derivative) to 1 (breakthrough innovation). Assesses five dimensions: conceptual novelty, technical/business model innovation, insight depth, cliché avoidance, and first-principles thinking. Accepts text, image, audio, video, or composite pitches."
}
```

### Task Structure

The function contains **10 tasks** organized into 5 dimensions (2 tasks each):

| Dimension | Task | Type | Response Scale |
|-----------|------|------|----------------|
| Conceptual Novelty | Domain Combination Novelty | vector.completion | Binary (2 responses) |
| Conceptual Novelty | Problem Framing Novelty | vector.completion | Binary (2 responses) |
| Technical/Business Model | Technical Approach Innovation | vector.completion | 4-level |
| Technical/Business Model | Business Model Innovation | vector.completion | 4-level |
| Insight Depth | Domain Knowledge Depth | vector.completion | 4-level |
| Insight Depth | Contrarian Insight Presence | vector.completion | Binary (2 responses) |
| Cliché Avoidance | Formula Language Avoidance | vector.completion | Binary (2 responses) |
| Cliché Avoidance | Specificity and Substance | vector.completion | 4-level |
| First-Principles | Assumption Questioning | vector.completion | Binary (2 responses) |
| First-Principles | Foundational Reasoning Evidence | vector.completion | 4-level |

## 3. Task Definitions

### Task 1: Domain Combination Novelty (Binary)

**System Prompt:**
```
You are an expert innovation analyst evaluating startup ideas for DOMAIN COMBINATION NOVELTY. Rate whether the idea combines elements from disparate domains in unexpected ways.

Consider:
- Does the idea connect concepts from different industries, fields, or problem spaces?
- Is the combination unprecedented or has it been done many times before?
- Does the synthesis create emergent properties greater than the sum of parts?
- Would the combination surprise domain experts?

You must choose between LOW (single domain or common combination) or HIGH (unexpected cross-domain synthesis).
```

**Responses:**
1. "LOW - The idea operates within a single familiar domain or combines elements that are commonly combined. No unexpected cross-domain synthesis."
2. "HIGH - The idea synthesizes disparate domains in unexpected ways, creating genuinely novel conceptual territory that would surprise experts."

**Output Expression:** `output['scores'][1]`

---

### Task 2: Problem Framing Novelty (Binary)

**System Prompt:**
```
You are an expert innovation analyst evaluating startup ideas for PROBLEM FRAMING NOVELTY. Rate whether the idea reframes an existing problem in a genuinely new way.

Consider:
- Does the idea define the problem differently than existing solutions?
- Is there a novel perspective on what the "real" problem is?
- Does the framing reveal something hidden about the problem space?
- Would the problem statement itself surprise people familiar with the space?

You must choose between LOW (conventional framing) or HIGH (novel reframing).
```

**Responses:**
1. "LOW - The idea accepts conventional problem framing and offers a solution within that established frame. The problem definition is standard."
2. "HIGH - The idea reframes the problem in a novel way that changes what solutions are even possible. The problem definition itself is innovative."

**Output Expression:** `output['scores'][1]`

---

### Task 3: Technical Approach Innovation (4-level)

**System Prompt:**
```
You are an expert innovation analyst evaluating startup ideas for TECHNICAL APPROACH INNOVATION. Rate whether the idea proposes genuinely novel technical approaches, algorithms, architectures, or uses of technology.

Consider:
- Does the idea propose new technical methods rather than applying existing ones conventionally?
- Is there innovation in how technologies are combined or integrated?
- Does the technical approach enable something previously impossible (not just easier)?
- Is the technology use substantive rather than decorative?

Choose the single best answer.
```

**Responses:**
1. "None: No meaningful technical component, or technology is purely conventional. Standard tech stack applied in standard ways."
2. "Low: Uses existing technology in standard ways. Technology is incidental to the idea, not a differentiator."
3. "Medium: Applies existing technology in somewhat novel ways or to new domains. Some technical creativity evident."
4. "High: Proposes genuinely novel technical approaches, architectures, or unprecedented technology combinations that enable new capabilities."

**Output Expression:** `output['scores'][0] * 0.0 + output['scores'][1] * 0.33 + output['scores'][2] * 0.67 + output['scores'][3] * 1.0`

---

### Task 4: Business Model Innovation (4-level)

**System Prompt:**
```
You are an expert innovation analyst evaluating startup ideas for BUSINESS MODEL INNOVATION. Rate whether the idea proposes novel mechanisms for creating, delivering, or capturing value.

Consider:
- Is there innovation in how value is created (new value propositions, new resource configurations)?
- Is there innovation in how value is delivered (new channels, new partnerships)?
- Is there innovation in how value is captured (novel pricing, new revenue mechanisms)?
- Does the business model challenge industry conventions?

Choose the single best answer.
```

**Responses:**
1. "None: Standard business model for the category. Nothing novel in how value is created, delivered, or captured."
2. "Low: Minor variations on established business models. Small tweaks to conventional approaches."
3. "Medium: Meaningful business model variations or creative combinations of existing models. Some novelty in value flow."
4. "High: Genuinely novel business model that creates new categories of value creation or capture. Would be studied in business schools."

**Output Expression:** `output['scores'][0] * 0.0 + output['scores'][1] * 0.33 + output['scores'][2] * 0.67 + output['scores'][3] * 1.0`

### Task 5: Domain Knowledge Depth (4-level)

**System Prompt:**
```
You are an expert innovation analyst evaluating startup ideas for DOMAIN KNOWLEDGE DEPTH. Rate whether the idea reveals deep understanding of the problem domain or appears to be surface-level pattern matching.

Consider:
- Does the pitch reveal non-obvious knowledge about the domain?
- Is there evidence of understanding why existing solutions fail?
- Does the idea anticipate objections that would only occur to domain experts?
- Is there evidence of genuine experience with the problem space?

Choose the single best answer.
```

**Responses:**
1. "Shallow: No evidence of domain understanding. Could have been generated from a template or trend report."
2. "Surface: Basic understanding of the domain but no non-obvious insights. Knows the space exists but not its nuances."
3. "Moderate: Shows solid domain knowledge with some non-obvious observations. Evidence of real engagement with the problem."
4. "Deep: Reveals expert-level understanding with insights that would surprise domain experts. Clear evidence of years of experience or research."

**Output Expression:** `output['scores'][0] * 0.0 + output['scores'][1] * 0.33 + output['scores'][2] * 0.67 + output['scores'][3] * 1.0`

### Task 6: Contrarian Insight Presence (Binary)

**System Prompt:**
```
You are an expert innovation analyst evaluating startup ideas for CONTRARIAN INSIGHT PRESENCE. Rate whether the idea contains a "secret"—a belief that is both non-consensus and potentially correct.

Consider:
- Does the idea rest on a belief that most people would disagree with?
- Is there an explanation for why the conventional wisdom is wrong?
- Does the contrarian element seem well-reasoned rather than arbitrary?

You must choose between ABSENT (follows conventional wisdom) or PRESENT (contains contrarian insight).
```

**Responses:**
1. "ABSENT - The idea follows conventional wisdom. Success would not prove anything surprising. No contrarian 'secret' is evident."
2. "PRESENT - The idea rests on a contrarian insight that, if correct, would overturn common assumptions. There is a non-obvious 'secret' here."

**Output Expression:** `output['scores'][1]`

### Task 10: Foundational Reasoning Evidence (4-level)

**System Prompt:**
```
You are an expert innovation analyst evaluating startup ideas for FOUNDATIONAL REASONING EVIDENCE. Rate whether the idea demonstrates reasoning from fundamental constraints and possibilities, rather than from analogy to existing solutions.

Consider:
- Does the pitch explain why the solution must be this way based on fundamental constraints?
- Is there evidence of working backward from physics, economics, or human nature?
- Does the reasoning avoid "because competitors do it" or "because that's how it's done"?
- Would the idea survive if industry conventions changed completely?

Choose the single best answer.
```

**Responses:**
1. "Pure Analogy: Entirely based on copying or adapting existing solutions. 'X for Y' reasoning with no fundamental justification."
2. "Mostly Analogy: Primarily analogical with minor first-principles elements. Some reasoning but mostly pattern-matching."
3. "Mostly First-Principles: Primarily derived from fundamentals with some analogical elements. Clear evidence of reasoning from constraints."
4. "Pure First-Principles: Entirely derived from fundamental constraints and possibilities. Industry-convention-independent reasoning throughout."

**Output Expression:** `output['scores'][0] * 0.0 + output['scores'][1] * 0.33 + output['scores'][2] * 0.67 + output['scores'][3] * 1.0`

## 4. Expressions Required

### User Content Expressions

All tasks use the same pattern to pass the idea to the evaluator:

```json
{ "$jmespath": "input.idea" }
```

This handles all input modalities (string, image, audio, video, array) appropriately.

### Output Expressions

**Binary tasks (5 tasks):** Extract probability of HIGH/PRESENT/AUTHENTIC/QUESTIONING response
```starlark
output['scores'][1]
```

**4-level tasks (5 tasks):** Weighted sum across response probabilities
```starlark
output['scores'][0] * 0.0 + output['scores'][1] * 0.33 + output['scores'][2] * 0.67 + output['scores'][3] * 1.0
```

### Final Aggregation

The function output aggregates task scores according to dimension weights from ESSAY_TASKS.md:

- **Insight Depth** (25%): Tasks 5, 6
- **Conceptual Novelty** (20%): Tasks 1, 2
- **First-Principles Thinking** (20%): Tasks 9, 10
- **Technical/Business Model** (20%): Tasks 3, 4
- **Cliché Avoidance** (15%): Tasks 7, 8

Since this is a scalar.function, the final aggregation happens automatically through the platform's aggregation of task outputs. Each task contributes equally within the function, and we'll rely on the natural averaging behavior.

**Note:** If explicit weighting is required, we would need an aggregation expression. For now, we implement equal task weighting (each of 10 tasks contributes 10%), which approximates the desired weighting since each dimension has 2 tasks.

By making predictions tradeable, we surface the tacit knowledge that already exists in research communities—senior scientists often know which results are shaky but have no venue to express this.
