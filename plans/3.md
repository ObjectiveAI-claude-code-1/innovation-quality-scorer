# Innovation Quality Scorer: Implementation Plan

## Overview

This plan defines the implementation of the `innovation-quality-scorer` function, a `scalar.function` that evaluates the innovation quality of startup ideas/pitches. The function accepts multi-modal input (text, image, audio, video) and produces a score from 0 (not innovative) to 1 (exceptionally innovative).

---

## Input Schema Structure

```json
{
  "type": "object",
  "description": "Input for the innovation quality scorer. Accepts a startup idea or pitch in various formats.",
  "properties": {
    "idea": {
      "anyOf": [
        {
          "type": "string",
          "description": "A text-based startup idea or pitch (elevator pitch, one-pager, detailed description, etc.)"
        },
        {
          "type": "image",
          "description": "An image-based pitch (pitch deck slide, product mockup, infographic, diagram)"
        },
        {
          "type": "audio",
          "description": "An audio pitch (recorded verbal description, podcast-style explanation)"
        },
        {
          "type": "video",
          "description": "A video pitch (founder presentation, product demo, pitch deck with narration)"
        }
      ]
    }
  },
  "required": ["idea"]
}
```

### Field Descriptions

- **idea**: The startup idea or pitch to evaluate. Can be provided in multiple modalities:
  - **string**: Text description of the idea, ranging from one-line elevator pitches to detailed multi-paragraph descriptions
  - **image**: Visual representation such as pitch deck slides, product mockups, or infographics
  - **audio**: Recorded verbal pitch or explanation
  - **video**: Video presentation combining visual and audio elements

---

## Input Maps

No input maps are needed. All 15 tasks evaluate the same single `idea` input. The input is passed directly to each task without transformation or mapping.

## Task Definitions

### Task 1: Conceptual Novelty — Core Idea Originality

**Type:** `vector.completion`

**System Prompt:**
```
You are an expert innovation analyst evaluating startup ideas for CORE IDEA ORIGINALITY. Assess whether the core concept represents a genuine departure from existing approaches.

Consider:
- Has this exact concept been attempted before? What makes this version meaningfully different?
- Does the idea reveal something hidden—a fresh perspective that was unnoticed?
- Would a knowledgeable domain observer be genuinely surprised by the insight?
- Does the idea expand the space of what's possible, enabling follow-on innovation?

Choose the option that best describes the originality of the core idea.
```

**User Prompt:** `'Evaluate the CORE IDEA ORIGINALITY of this startup idea:\n\n' + str(input['idea'])`

**Responses:**
1. "Category Creator: Defines an entirely new problem space or solution category; genuinely unprecedented approach"
2. "Meaningful Variation: Introduces substantive modifications that address real limitations or expand possibilities significantly"
3. "Minor Variation: Adapts existing concepts with some modifications, but the core approach remains familiar"
4. "Pure Derivative: Applies an existing successful concept to a new vertical with minimal adaptation ('X for Y')"
5. "Redundant: Essentially identical to existing solutions with no meaningful differentiation"

**Output Expression:** `output['scores'][0] * 1.0 + output['scores'][1] * 0.75 + output['scores'][2] * 0.5 + output['scores'][3] * 0.25 + output['scores'][4] * 0.0`

## Implementation Notes

1. **Task Independence**: All 15 tasks evaluate independently and can be parallelized.

2. **Score Aggregation**: The final function score will be the arithmetic mean of all 15 task outputs, producing a value between 0 and 1.

3. **Multi-Modal Handling**: The `anyOf` schema allows any single modality. Tasks using `str(input['idea'])` should handle image/audio/video appropriately through the underlying system.

4. **Response Ordering**: Responses are ordered from best (1.0) to worst (0.0) for consistency across tasks.

5. **Prompt Consistency**: All user prompts follow the same structure for predictable behavior.
